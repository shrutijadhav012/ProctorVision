Student Behavior Monitoring During Exam System

This project is a smart online examination monitoring system designed to enhance the security and fairness of remote assessments. The system utilizes advanced Computer Vision and Machine Learning techniques to continuously analyze live webcam footage and audio input. It can detect multiple individuals in the frame, identify unauthorized gadgets such as mobile phones and laptops, monitor suspicious movements, and transcribe background conversations. Real-time alerts and warning notifications help maintain examination integrity while reducing the need for continuous human supervision.

The project demonstrates the practical application of Artificial Intelligence, Object Detection, Computer Vision, and Audio Processing in solving real-world challenges in online education and remote examinations. The system is designed with scalability and usability in mind, making it suitable for academic institutions, certification platforms, and online assessment environments.

Key Features:

Real-time candidate monitoring
Multiple person detection
Electronic gadget detection
Background audio transcription
Suspicious activity alerts
Automated warning system
User-friendly monitoring interface
Computer Vision-based examination surveillance
AI-powered decision support for online invigilation
